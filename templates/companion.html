Download for Android

Share your screen, microphone, camera and selected files. Enable the app’s accessibility service yourself for remote taps, swipes and text.

{% if android_app_available %}Download ZDesk for Android (.apk){% else %}

The Android development APK is building. Its download will appear here when ready.

{% endif %}
  1. Install the APK and open ZDesk.
  2. Enter your dashboard connection code or passcode.
  3. Choose sharing permissions. Select Camera and front/rear camera if you want to show surroundings. Enable ZDesk in Accessibility settings for control.
  4. Tap Start sharing and approve Android’s capture prompt.

Android requires approval for every new screen capture. Leaving setup keeps an active session in a visible notification; use Stop sharing there or in the app to end access. No boot-time, lock-screen or protected-screen access.

For camera viewing, enable Camera locally for the current session, then open the device session in your dashboard and choose Open camera view. Stop camera or Stop sharing ends capture. Camera sharing is not remembered.

Development APK for Android 8+. It is self-signed and not a Play Store release. Updates may require reinstalling if its development signing key changes.

Download for Windows

Use the native companion for mouse and keyboard control, system and microphone audio, locally enabled camera sharing, dedicated-folder file exchange and optional reconnect at sign-in.

{% if windows_app_available %}Download ZDesk for Windows (.exe)

No Python or VS Code required. Save ZDesk.exe in a permanent folder and double-click it to open the connection window.

  1. Open the app and paste a one-use code or reusable connection passcode from your dashboard.
  2. Choose Remember this computer and reconnect automatically.
  3. Use Add ZDesk desktop shortcut for an icon you can click later.
  4. Enable Keep available in the tray to close the window while staying connected. You can also enable sign-in startup.

The app is unsigned. Windows may ask you to verify its publisher.
